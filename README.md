# pairclear.github.io

The hub page for PairClear's free tools: https://pairclear.github.io/

`robots.txt` lists the sitemap of every tool site, so a crawler (or an indexing script) that reads it finds all tool pages. When a new tool gets a GitHub Pages site, add its card in `index.html` and its `Sitemap:` line in `robots.txt`.

Made by [PairClear](https://pairclear.com/en/?utm_source=github&utm_medium=readme&utm_campaign=hub). Code MIT.
